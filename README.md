## HW1
1. Import a 3D model from Free3D ([Plastic Cup](https://free3d.com/3d-model/plastic-cup-high-poly-version-79161.html)) and drag it from the Project window into the scene.
2. Adjust the Scale of the model in the Inspector:
  - Scale X: 1 → 0.74
  - Scale Y: 1 → 0.83
3. Rotate the model around all three axes using the Rotation values in the Inspector:
  - X axis: -1.1
  - Y axis: -30.6
  - Z axis: -1.61
